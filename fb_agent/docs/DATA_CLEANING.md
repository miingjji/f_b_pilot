# 데이터 정제 (결측치 처리)

`data/f_b_menu_data.md`(엑셀 18시트를 마크다운으로 덤프한 파일)의 결측치(`NaN`)를 시트별로 정리합니다.
원본 파일은 수정하지 않고, 결과는 `data/cleaned/수불부/2025/2025-12/`에 CSV로 저장합니다 (월별 수불부는 `data/cleaned/수불부/<연도>/<YYYY-MM>/`, 상세는 `LEDGER_RECONCILE.md`) (`.gitignore` 처리: 실제 매장 데이터).

```bash
python -m prep                         # 등록된 시트 전부
python -m prep --only 실사재고 입고내역   # 일부만
python -m unittest test_prep test_prep_stock test_prep_sales test_prep_summary test_prep_runner
```

## 왜 일괄 `dropna()` / `fillna(0)`이 아닌가

이 파일의 `NaN`은 한 가지가 아닙니다.

| 종류 | 예 | 처리 |
|---|---|---|
| 구조상 빈칸 (병합 셀·제목행·미사용 열) | 머리글 `Unnamed: N`, 빈 열 | 머리글을 펴고 빈 열은 삭제 |
| 의미 있는 빈칸 ("해당 없음") | 취소구분 비어 있음 = 정상 거래 | 의미 있는 값으로 채움 |
| 계산으로 복원 가능한 빈칸 | 수량 = 중량 ÷ 환산단위 | 검증된 산식으로 계산 |
| 진짜 결측 | 돈이 오갔는데 결제수단이 없음 | **채우지 않고 오류로 중단** |

`매출입력`은 NaN이 없는 행이 0개라서 `dropna()`를 하면 데이터가 전부 사라지고, `fillna(0)`은 문자 열에 `0`을 넣습니다.
규칙으로 설명되지 않는 결측은 조용히 채우지 않고 `UnhandledMissingError`로 알립니다.

### 규칙 요약

- **매출입력**: 취소구분 → `정상`, 할인수단 → `할인없음`, 객층 → `미기록`, 결제수단 → `결제없음`(실매출_합계가 0원일 때만),
  메뉴 없는 주문취소 영수증의 메뉴 열 → `해당없음`(주문번호는 0). 행은 지우지 않음.
- **실사재고 / 입고내역**: 상세표만 잘라 2줄 머리글을 한 줄로 폅니다(`재고실사_수량`, `1일_금액` 등).
  코드 없음 → `없음`, 규격·과세구분 없음 → `미기재`. 수량 빈칸은 중량(·금액)이 0이면 0, 아니면 `중량 ÷ 환산단위`.
  `당월발주` 빈칸 → 0, `차이` 빈칸 → `당월발주 − 당월합계수량`. 전부 빈 열(`전월미입고`)은 삭제.
- **판매및할인**: 비어 있는 열과 왼쪽과 똑같은 조회 열을 삭제하고 BOM유무 빈칸을 `미기재`로. 상품코드가 중복인 행은 **삭제하지 않고 `중복행`으로 표시**.
- **수불요약**: 블록마다 표로 분리. 거래가 없는 항목 → 0, 병합 셀의 빈칸(구분) → 위 행 값, 비율 산정 불가 → 0.
  값이 1/6행뿐이고 산식을 알 수 없는 `매출대비` 열은 삭제(원래 값은 점검 결과에 기록).

각 시트의 처리 내역은 `<시트>_결측치_처리내역.csv`(열, 채운 개수, 규칙, 채운 값)에 있습니다.

## 검증 (점검 기준은 실제 값에서 성립함을 확인한 관계만)

- 상세표의 합 = 시트의 합계행 (실사재고 수량·중량, 입고내역 수량·중량·금액, 판매및할인 금액)
- 행별 `당월합계 = 일자 합`, `수량 × 환산단위 = 중량`, `차이 = 당월발주 − 당월합계수량`
- 수불 마감: `기초 + 입고 − 출고 = 기말`, 합계행 = 계정별 합
- `객단가 = 매출 ÷ 객수`, `로스금액 = 실사 − 이론`, `로스율 = 로스금액 ÷ 실사기준 사용`, `차이 = 기말 − 실사`

### 규칙 요약

- **공통**: 소계·합계 행은 점검에 쓰고 삭제, `#NUM!` 칸은 소계·합계 행에만 있어 함께 사라짐, 쉼표 숫자는 숫자로 변환(변환 불가 값이 있으면 오류로 중단),
  병합 셀로 첫 행에만 있던 매장명·입고일자·청구번호는 아래 행에 채움, 전부 빈 열·고정 코드 열은 삭제.
- **매출일자별**: 원본에 행이 없는 날(1/1, 2/16~17, 3/9, 4/13, 5/18, 6/8, 7/13, 8/24, 9/24~25)은 **결측이 아니라 휴무로 추정**해서 `영업여부=무매출일`, 매출·영수증 0으로 채움(휴무 여부는 확인 필요).
  매장별 4열은 전체 합계 열과 값이 같아 삭제. `영수증당_순매출`은 순매출 ÷ 영수증수(영수증 0이면 0).
- **구매청구**: 청구번호 = `청구일자-R_NO(3자리)`로 복원(원본 값과 100% 일치 확인). `DEL_CHK=N`은 발주만 하고 입고가 없는 행이라 입고일자 `미입고`, 번호 열 0, `청구후_입고까지_일` -1.
  `입고수량_차이` = 입고수량 − 발주수량, `청구후_입고까지_일` = 입고일 − 청구일(리드타임 학습용).
- **입고**: 발주 없는 일반입고(반품) 1건의 발주번호는 0. 품명·규격·태그·사양코드는 `품목명_원본`에서 분리(원문 보존).

### 검증

- 입고·구매청구: 수량·금액·부가세·합계 합 = 합계 행, 금액 + 부가세 = 합계(전 행), 일 소계(223일) = 일별 합, 청구번호 복원값 = 원본 값, 합쳐진 날짜 열 = 개별 날짜 열.
- 매출일자별: 4개 합계 = 총 합계 행, 요일 = 실제 요일, 순매출 ≤ 실매출 ≤ 총매출(전 일), 순번 연속.
- **교차**: 입고 5,892행 중 5,872행이 구매청구와 (입고월, 입고번호, 순번) 키로 일치하고 수량·금액이 모두 같음. 나머지 20행은 2025-12 청구 → 1/2 입고분 19행(구매청구 파일이 1/1 청구분부터라 없음)과 발주 없는 반품 1건.
