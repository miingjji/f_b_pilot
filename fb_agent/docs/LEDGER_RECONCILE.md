# 월별 수불부 정제와 POS 대조 (2025-01 ~ 2026-09)

원본 `data/source/수불부/<YYYY-MM>.md` → 정제본 `data/cleaned/수불부/<YYYY-MM>/` (21개월).
정제한 시트는 수불요약(8개 표), 실사재고, 입고내역이다. 매출입력·판매및할인은 POS와 겹쳐서 이번에는 정제하지 않았다.

```bash
python -m prep --only 실사재고 입고내역 수불요약 --src data/source/수불부/2026-01.md --out data/cleaned/수불부/2026-01
python -m prep.ledger_reconcile      # data/cleaned/수불부/POS_대조_월별.csv
```

`cleaned/수불부/2025-12/`는 기존 `cleaned/` 루트의 12월 파일과 내용이 같다 (바이트 단위로 확인).

## 정제 결과

21개월 모두 남은 결측 0개. 시트 간 점검은 아래 원본 값 차이를 빼고 통과한다.

월마다 한두 칸씩 비어 있어 규칙을 추가했다 (`prep/stock_sheets.py`). 값이 있는 칸에서 관계가 성립함을 먼저 확인하고 쓴다.

| 규칙 | 근거 |
|---|---|
| 일자별 금액 빈칸 = 수량 × 단가 | 값이 있는 칸에서 성립 (21개월 전체에서 어긋나는 칸은 아래 3번의 1칸뿐) |
| 일자별 중량 빈칸 = 수량 × 환산단위 | 같음 (어긋나는 칸은 아래 3번의 1칸뿐) |
| 당월합계 빈칸 = 일자 합 | 값이 있는 행에서 성립 |
| 단가 ↔ 단가_g (= 단가 ÷ 환산단위) | |
| 구분 빈칸 = 거래처명+과세면세 | 구분이 `CK`인 행은 규칙 밖 (거래처 대신 조달 경로) |
| 실사재고에서 환산단위·수량·중량이 모두 빈 행 = 미실사, 수량·중량 0, 환산단위 1 | 다른 달에 같은 품목이 환산단위 1·중량 0으로 있음 |

### 원본에서 발견한 문제 (고치지 않고 알림)

1. **당월합계_중량이 일자 합보다 작은 행**: 2025-02 1행, 2025-04 1행, 2026-05 2행, 2026-06 5행, 2026-07 6행, 2026-08 2행, 2026-09 4행. 일자 중량이 빈칸인 날을 원본 합계가 빼고 있다 (수량·금액 합계에는 들어 있음). 빈칸은 채웠고 원본 합계는 그대로 둔다.
2. **염지제(꿔바)_575g/pk의 단가_g가 0** 인데 단가는 3,486원 (2025-12 확인; 2025-01~12 월마다 단가_g 불일치가 1행씩 있음). 단가_g를 쓰지 말고 단가 ÷ 환산단위를 쓸 것.
3. 2026-04 일자별 금액 1칸이 수량 × 단가와 다르고, 2026-06 일자별 중량 1칸이 수량 × 환산단위와 다르다.
4. 2025-04 파일의 시트 제목이 "3월"이다 (데이터는 4월).

## POS 대조 (`POS_대조_월별.csv`)

### 수불 마감·이월
- 기초 + 입고 − 출고 = 기말: **21개월 모두 성립**.
- 전월 기말 = 당월 기초: 대부분 수만 원 이내. 큰 차이는 **2025-03 기초가 2월 기말보다 1,990,869원 큼**, **2025-06 기초가 5월 기말보다 1,965,905원 작음**. 크기가 비슷하고 부호가 반대다. 사용자 설명: 6월 파일이 "기초" 수불부라 기초재고를 새로 잡은 것으로 보임. 대조표 `비고` 열에 표시만 하고 값은 고치지 않았다.

### 매출·객수 (수불요약 vs POS 정산 월 순매출)
21개월 중 16개월은 매출이 원 단위까지 같다. 차이가 나는 5개월:

| 월 | 수불요약 − POS | 원인 |
|---|---|---|
| 2025-04 | +9,091원 | 수불요약 값이 다름 (객수는 같음) |
| 2025-07 | −368,182원, 객수 −21 | **7/31 하루** — 수불부 매출입력 4,853,227 vs POS 5,221,409 |
| 2025-12 | +614,273원, 객수 −2 | **12/31 하루** (수불부 7,430,202 vs POS 6,815,929), 12/18에 200원 |
| 2026-02 | **+13,793,998원** | 수불부 자기 매출입력 합(137,940,310)과 수불요약(151,734,350)이 다름. 수불요약 오입력으로 보임. 매출입력은 POS와 42원 차이 (2/19) |
| 2026-03 | −85,455원, 객수 −5 | 수불부 매출입력은 POS와 정확히 같고 수불요약만 다름 |

그 밖에 **2025-09 수불요약 객수가 9,234**로 POS 6,234보다 정확히 3,000 많다 (오타로 보임).

### 입고 (수불요약 입고_구매 vs POS 입고 공급가)
수불부 입고가 POS의 1.6~2.3배다. POS 입고 리스트는 구매청구 품목(원재료 위주)만이라서 같은 값이 아니다. 월별 비율은 CSV의 `입고_비율`. 2025-12가 1.83으로 낮은 편이다.

## 결론
- 학습·예측 기준은 계속 POS를 쓴다 (`data-source-decisions`).
- 수불부에서 쓸 값은 실사재고, 폐기·로스, 수불 마감이다. 이 값들은 항등식이 맞으므로 쓸 수 있다.
- 수불요약의 **매출·객수는 쓰지 않는다** (위 6개월에 오류).

## 타_폐기 정제 (`prep/waste_sheet.py`)

시트는 두 표다. `타_폐기_상세_정제.csv` 는 폐기 기록(일자·품목·수량·중량·사유), `타_폐기_품목별_정제.csv` 는 품목별 월 합계(밥은 쌀로, 라웨이황과는 재료로 분해한 행 포함)다. 맨 아래 '합 계' 행은 품목별 표의 합이고, 21개월 모두 일치한다.

- 2025-01 ~ 2026-05는 한 달치를 월말 하루에 몰아 적었고(`기록방식`=월말일괄), 2026-06부터 일별이다.
- `사유_분류`: 유통기한 경과, 마감 후 잔량, 직원 실수, 품질·상태 불량, 작업 후 자투리·불량, 시즌 종료, 판매 종료·중단, 설비 고장, 백화점 휴무, 업체 변경, 라벨 손상, 교육·테스트·촬영, 기타. 원문은 `사유_원문`에 그대로 있다.
- 채운 칸: 중량 칸에 `304g`처럼 단위 글자가 붙은 칸(2026-07 1개)은 글자를 뗐다. 환산단위·거래처·품명·규격이 비면 품목별 표의 같은 코드 값, 수량이 비었거나 0인데 중량이 있으면 중량 ÷ 환산단위. 2026-07의 크림새우소스는 수량 칸에 환산단위(1000)가 들어가 있어 다시 계산했다.
- 원본 문제: 2026-04에 일자가 2026-05-01인 기록 1개(사유는 4월), 상세와 품목별 표의 중량이 다른 코드가 몇 달에 1~3개(밥·라웨이황과 분해 행과 겹치는 홍고추·청오이 등은 품목별 표에 직접 폐기분이 없음).

## 재고를 발주 엔진에 연결 (`reorder_engine.py`)

`Engine.recommend(D, use_stock=True)` 는 직전 월말 실사로 재고를 추정한다: 실사 수량(규격 단위)을 같은 달 구매청구 발주수량 ÷ 수불부 입고수량 비율로 발주단위로 환산(95% 품목은 비율 1, 비율이 불안정한 품목은 제외 → 231개 품목에 재고) + 실사 뒤 도착한 입고 − (평소 소비 속도 × 예상 매출). 실사 후 14일 안(`STALE_DAYS`)에만 쓴다.

검증 (2026-01~09, 실사 후 14일 안 3,230건, 모델은 2025 하반기로 학습):

| 방법 | 정밀도 | 재현율 | F1 |
|---|---|---|---|
| 주문 습관 (기존) | 68.8% | 94.5% | **79.6%** |
| 추정 재고 < 입고 전 예상 소비 | 65.1% | 37.8% | 47.8% |
| 위 기준을 4배로 느슨하게 | 64.2% | 85.2% | 73.2% |
| 습관 모델 + 재고 여유를 특성으로 추가 | 68.3% | 91.3% | 78.2% (습관만 78.3%, AUC 0.83 동일) |

재고만으로는 습관보다 못 맞히고, 습관 모델에 더해도 나아지지 않는다. 주문이 '정해진 날 정해진 양' 습관에 가깝기 때문이다. 그래서 실사 재고를 쓰는 곳은 두 가지다.
1. **주문 간격이 14일보다 길어 습관으로 못 보던 품목('재고 확인')**: 재고로 판단한다. 560건 기준 실제 주문 비율 11%, 재고 부족 판정의 정밀도 23%·재현율 64%, 재고 여유의 AUC 0.71.
2. **습관으로 '발주'인 품목**: 추정 재고를 보여 주고, 입고 전 예상 소비의 4배를 넘으면 '재고 넉넉' 주의를 붙인다(판단은 바꾸지 않음). 습관 발주의 적중률이 재고 부족할 때 75~80% → 소비의 8배 넘을 때 47%로 떨어지기 때문이다.

화면(`발주 추천`): 기준일이 실사 후 14일 안이면 추정 재고를 쓰고, 넘으면 쓰지 않는다고 알린다. 지금(2026-10-21)은 마지막 실사(2026-09-30)로부터 21일이라 재고 추정은 꺼져 있다. 새 달의 수불부를 올리면 켜진다.
